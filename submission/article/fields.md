Title (max 255 characters):
Reflex Arc: giving a coding agent a nervous system with Strands Decider 2B

Description (max 512 characters):
Most AI coding agents only find out they went wrong after the damage is done. Reflex Arc puts a fast, confidence-aware Strands Decider 2B check inside the generation loop and before every action, so it stops the agent the instant it hallucinates a dependency, loops, drifts off task, or composes a destructive command. On held-out cases the reflex hit 83.8% accuracy, 100% when confident, at about 15x lower cost than asking an LLM the same questions.
